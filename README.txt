PLAN TRENINGOWY 3.0 — PWA

Wersja 3.0 zawiera:
- pełny manifest PWA,
- service worker i działanie offline po pierwszym uruchomieniu,
- ikony aplikacji,
- przycisk „Zainstaluj” na urządzeniach obsługujących instalację,
- historię treningów, objętość, ciężary/powtórzenia oraz pomiary wagi i pasa.

WAŻNE:
PWA wymaga uruchomienia z HTTPS (albo localhost podczas testów). Samo otwarcie index.html z pliku ZIP nie wystarczy do instalacji jako PWA.

Najprostsza metoda:
1. Rozpakuj ZIP.
2. Umieść pliki na dowolnym hostingu obsługującym HTTPS.
3. Otwórz adres strony na telefonie.
4. Android/Chrome: wybierz „Zainstaluj aplikację” lub użyj przycisku w aplikacji.
5. iPhone/Safari: Udostępnij → „Dodaj do ekranu początkowego”.

Dane treningowe są przechowywane lokalnie w przeglądarce urządzenia.
